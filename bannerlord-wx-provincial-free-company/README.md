# Bannerlord WX Provincial Free Company

中文工作名：帝国行省自由军。

本项目为《骑马与砍杀 2：霸主》`v1.4.8` 制作一套使用原版资产的帝国行省自由军兵种体系。

## 当前版本

`v0.5.2-five-point-prototype`：在 v0.5.1 数据层与诊断命令之上，包装当前 `VolunteerModel`，仅对五个试点聚落（核心区萨涅俄帕、北境阿耳戈隆、南境沃斯特鲁姆、西境加隆托、东境安普雷拉，联合覆盖 0/30/55/80 四档概率）启用"`imperial_recruit` → 地域 T1"的概率替换；贵族兵与其余 111 个征兵点保持原版。

本版本第一次真正改变志愿兵结果，但范围严格限于五点试点；全图启用留待长期验收数据确认后。

War Sails 的自定义战斗界面不依据 `NavalSoldier` 或 `Mariner` 识别非诺德水兵，而依赖兵种内部 ID 中的小写 `marine`。v0.4.5 因此仅调整北境 T4/T5 内部 ID 及升级引用，不改变中英文显示名、装备或战斗数值。北境 T1–T3 仍为普通陆军，T4/T5 仍分别使用 `NavalSoldier=1` 与 `Mariner=80/90`。

```text
北境边民 T1 → 北境行省征召兵 T2 → 北境行省辅兵 T3 → 北境自由军盾斧兵 T4 → 北境自由军盾卫 T5
南境边民 T1 → 南境行省征召兵 T2 → 南境行省掷矛兵 T3 → 南境自由军突击兵 T4 → 南境自由军破阵卫 T5
西境边民 T1 → 西境行省征召兵 T2 → 西境行省弩手 T3 → 西境自由军重弩手 T4 → 西境自由军破甲弩卫 T5
东境边民 T1 → 东境行省征召兵 T2 → 东境行省骑射手 T3 → 东境自由军游骑射手 T4 → 东境自由军游骑卫 T5
```

四种 T1 不再复用帝国新兵的核心穿搭：北境使用冻原布衣、毛皮兜帽与高地裹腿；南境包含赤膊持双手农具的苦役和南方贫民；西境使用兜帽、麻布衣与工匠农具；东境使用游牧软帽、草原长衣与徒步猎弓。v0.4.2 将东境 T1 改为猎弓、9 支粗制猎箭和单手小镰刀，弓术降至 15，避免低阶单位兼具持久远程火力与强力双手近战。

四种 T2 分别形成盾斧、标枪双手、轻弩和徒步弓手训练。南境 T2 的两套装备分别采用阿塞莱包头巾配帝国软甲、沙漠帽配沙漠软垫布甲；东境 T2 不配坐骑，升级至 T3 时才正式转为骑射兵。

本版本尚未启用 C# 地域志愿兵模型。旧共同 T2 `wx_provincial_levy` 与原版帝国新兵追加入口已经删除，四条地域树暂时作为未接入志愿兵池的独立根节点存在；自定义战斗仍可选择全部地域兵种，普通战役暂时无法正常征募，且不兼容持有旧共同 T2 的存档。

`v0.1.1` 标签保留已通过实机测试的 T2 原型，`v0.2.0` 标签保留单线完整原型。`v0.3.0` 使用新的地域兵种 ID，建议使用新测试存档。

北境线保留帝国头盔、胸甲与护具作为军事骨架，以诺德毛皮肩甲、北境圆盾、战斧和少量北境头盔建立地域特征。T3 使用朴素毛皮披肩，T4 使用长亚麻毛皮披肩，T5 两套延续长毛皮、一套使用狼皮披肩。

南境线现已正式改造为“南境行省掷矛兵→南境自由军突击兵→南境自由军破阵卫”。全线保持步兵分组、无盾、每套一组标枪，以双手塔巴尔斧、行刑斧、重型行刑斧或南方双手锤完成冲击。防具继续以帝国软甲、锁甲、军团甲和多数帝国头盔为骨架，以南方披巾、皮护肩、青铜鳞片肩甲和一套 T5 黄铜盔表现阿塞莱边疆影响。

西境线现已正式改造为“西境行省弩手→西境自由军重弩手→西境自由军破甲弩卫”。全线归入远程分组且不配盾牌；T3 使用轻弩与单组弩矢，T4–T5 使用双组弩矢，分别换装重弩与缠弦弩。近战以瓦兰迪亚单手剑为主，T5 保留一套长柄偃月武器变体；其核心仍是用持续火力交换盾牌和持线能力。

v0.3.8 将西境 T3–T4 的纯刺击长矛替换为瓦兰迪亚单手剑，并将单手熟练度提高至 70/95；T5 单手提高至 115，两套装备分别使用高阶瓦兰迪亚剑和长柄偃月武器。全线仍然无盾，T4–T5 仍保留双份弩矢，因此近战自保得到改善但没有复制原版盾弩兵。

东境线现已正式改造为“东境行省骑射手→东境自由军游骑射手→东境自由军游骑卫”。全线归入骑射分组，T3 携带一袋 24 支草原箭，T4–T5 携带一袋 36 支堆叠草原箭，并以东方长矛和帝国剑承担箭尽后的侧翼冲击与追击。三阶均保留草原马匹，马具改用帝国条纹皮马具与具装半身鳞甲。

v0.3.8 将东境 T3 换装反曲弓并把弓术提高至 70；T4–T5 改用单袋 36 支堆叠草原箭，弓术提高至 100/130，单手提高至 90/115。草原马匹继续保留，但 T3 改用帝国条纹皮马具，T4–T5 改用帝国具装半身鳞甲，使其成为帝国防护体系下的行省骑射军。

原版 T5“帝国禁卫射手”和“帝国军士弩手”的三套随机装备通过 `spnpccharacters.xslt` 精确改用原版 `empire_lord_helmet`（禁卫射手盔），不再追加重复装备套装；除头盔外不修改两者的武器、甲胄、技能与升级关系。

西境 T5 的两套随机装备现已统一使用 `kettle_hat_over_mail_coif`（锅帽衬链甲围帽）；武器、身体护甲、技能与远程分组保持不变。

## 安装测试

参见 `BUILDING.md`。推荐使用 `scripts/deploy.ps1` 组合 XML 数据与编译后的 DLL，避免手动漏掉 `bin/Win64_Shipping_Client`。在启动器中同时启用 War Sails / NavalDLC 与本模块后进行测试。请先备份存档；开发版本不承诺向前或向后兼容。

## 安全边界

- 不修改 Native、SandBoxCore、Sandbox、StoryMode、CustomBattle 或 NavalDLC 官方文件。
- 不收录游戏存档、崩溃日志、账号凭据或官方游戏资产。
- 当前版本包含本 MOD 自己的只读 DLL，但不包含 Harmony、第三方运行时或任何官方游戏 DLL；地域志愿兵模型尚未注册。因使用诺德毛皮装备，模块要求 War Sails / NavalDLC `v1.2.8`。
