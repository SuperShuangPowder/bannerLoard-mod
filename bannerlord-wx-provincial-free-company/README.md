# Bannerlord WX Provincial Free Company

中文工作名：帝国行省自由军。

本项目为《骑马与砍杀 2：霸主》`v1.4.8` 制作一套使用原版资产的帝国行省自由军兵种体系。

## 当前版本

`v0.3.2-provincial-levy`：共同 T2 分出北、南、东、西四条 T3–T5 地域分支；北境线和共同 T2 已完成第一轮深化，其他三条路线仍为结构占位配置。

```text
帝国新兵（原版 T1）
└─ 行省征召兵（T2，无盾双手冲击步兵）
   ├─ 北境行省辅兵（T3）→ 北境自由军盾斧兵（T4）→ 北境自由军盾卫（T5）
   ├─ 南境行省辅兵（T3）→ 南境自由军战士（T4）→ 南境自由军老兵（T5）
   ├─ 东境行省辅兵（T3）→ 东境自由军战士（T4）→ 东境自由军老兵（T5）
   └─ 西境行省辅兵（T3）→ 西境自由军战士（T4）→ 西境自由军老兵（T5）
```

`v0.1.1` 标签保留已通过实机测试的 T2 原型，`v0.2.0` 标签保留单线完整原型。`v0.3.0` 使用新的地域兵种 ID，建议使用新测试存档。

北境线使用帝国胸甲和护具维持帝国身份，以北境圆盾、战斧和少量北境头盔建立地域特征。南境、东境、西境的外观、装备、技能及战斗力差异将在后续版本逐条实现。

T2 行省征召兵使用帝国轻装与民用服装，不配发制式盾牌和单手剑，以双手斧、双手锤、钩镰枪和少量投掷武器作战。其战术定位是高风险的低阶冲击兵，而不是帝国 T2 步兵的弱化复制。

## 安装测试

将 `src/WXProvincialFreeCompany` 整个文件夹复制到 Bannerlord 的 `Modules` 目录，在启动器中启用模块后进行测试。请先备份存档；开发版本不承诺向前或向后兼容。

## 安全边界

- 不修改 Native、SandBoxCore、Sandbox、StoryMode、CustomBattle 或 NavalDLC 官方文件。
- 不收录游戏存档、崩溃日志、账号凭据或官方游戏资产。
- 当前版本不包含 DLL、Harmony 补丁或第三方运行时依赖。
