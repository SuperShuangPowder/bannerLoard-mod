# WX Provincial Free Company

《骑马与砍杀 2：霸主》帝国行省自由军兵种扩展模组。

## 当前里程碑

`v0.2.0-full-line-prototype`：帝国行省自由军完整兵种线原型。

- 新增 T2 至 T5 完整单线升级路线：行省征召兵 → 行省辅兵 → 自由军团战士 → 自由军团老兵。
- 从原版 `imperial_recruit` 追加第三条升级目标；原有帝国步兵和帝国弓箭手分支保持不变。
- 全线使用原版长矛、单手剑／斧、鸢盾、投枪和帝国护具。
- 已加入简体中文兵种名称；非简体中文环境使用英文后备名称。
- 当前不包含 DLL、Harmony 补丁、自定义模型、贴图或场景。

## 开发基线

- Bannerlord `v1.4.8`
- War Sails / NavalDLC `v1.2.8`（兼容性测试环境，不是必需依赖）

## 安全原则

本模组只在自己的模块目录中工作，不修改 Native、SandBoxCore、Sandbox、StoryMode、CustomBattle 或 NavalDLC 的任何文件。
