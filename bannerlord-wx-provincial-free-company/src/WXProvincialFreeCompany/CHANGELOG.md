# Changelog

## v0.4.4-naval-tier-threshold — 2026-11-06

- 根据设计复核，将北境路线的海军士兵身份从“全线固有属性”收紧为“T4 起获得的职业训练成果”。
- 北境 T1“北境边民”、T2“北境行省征召兵”和 T3“北境行省辅兵”移除 `NavalSoldier` 特性，并同步移除 50/60/70 的 `Mariner`，在海战中按普通陆军处理。
- 北境 T4“北境自由军盾斧兵”继续保留 `NavalSoldier=1` 与 `Mariner=80`；T5“北境自由军盾卫”继续保留 `NavalSoldier=1` 与 `Mariner=90`。
- 不修改北境全线的等级、装备、陆战技能、战斗分组和升级关系；东境粗制猎弓及其他三条地域路线保持 v0.4.3 状态。
- 模块继续依赖 NavalDLC `v1.2.8`，仍为 XML/XSLT 数据模组，不包含 DLL 或 Harmony。

## v0.4.3-crude-bow-naval-north — 2026-11-06

- 新增数据物品 `wx_crude_hunting_bow`（粗制猎弓），复用原版猎弓模型与动作，不进入商店；穿刺伤害由原版猎弓的 40 下调为 18，精度由 85 下调为 72，弹速由 64 下调为 52，射击速度由 87 下调为 82。
- 东境 T1 两套装备均由原版 `hunting_bow` 改用粗制猎弓；继续保留 9 支粗制猎箭、弓术 15、单手小镰刀与无马配置，使其定位收敛为低精度、低杀伤的短时远程骚扰兵。
- 北境 T1–T5 全线新增 `NavalSoldier=1` 海军士兵特性，并按 50/60/70/80/90 配置 `Mariner` 航海熟练度，成长曲线与 NavalDLC 诺德兵种保持一致。
- 北境线的陆战等级、武器、防具、普通战斗技能和升级关系不变；本次专精用于免除普通部队的主要海战惩罚，并强化其接舷重步兵身份，而非追加陆战数值。
- 模块继续使用既有 NavalDLC `v1.2.8` 依赖，仍为 XML/XSLT 数据模组，不包含 DLL、Harmony、自定义模型或贴图。
