## 维护规则

- 当前实现优先查阅项目根目录的 `PROJECT_HANDOFF.md`、`README.md`、`BUILDING.md`、CHANGELOG和实际源码。
- 两册日志用于保存完整设计演进，新增记录应写入对应分册，不再恢复单一混合日志。
- 本地知识库外层可能保留便于阅读的镜像副本；提交远端前必须确保本目录中的Git版本同步更新。
- 地图数据由 `design/imperial_settlements.tsv` 和生成脚本维护，不应只在HTML中手工修改。
